# Change Log

All notable changes to the "tonatools" extension will be documented in this file.

This project adheres to [Keep a Changelog](http://keepachangelog.com/).

## [0.0.1] - 2026-08-23

### Added

- `File: Copy file name` — copies the active file's name.
- `File: Copy current workspace directory` — copies the active file's folder, relative to the workspace root.
- `Git: Copy file location in remote url` — copies a link to the active file on its git remote, with line/range anchors.
- `tonatools.git.remoteTemplates` setting for custom or self-hosted git host URL templates. `github.com`, `gitlab.com` and `bitbucket.org` are built in.
